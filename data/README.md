# data

| 파일 | 내용 | 기록 수 |
| --- | --- | --- |
| `mon_standard.pkl` | monitored 95개 사이트 (페이지 950개 × 접속 20회) | 19,000 |
| `unmon_standard10.pkl` | unmonitored | 10,000 |
| `unmon_standard10_3000.pkl` | unmonitored 축소판 (10,000의 일부) | 3,000 |
