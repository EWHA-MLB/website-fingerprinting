Random Forest(RF) 추가 실험 1(Feature Group별 단독 학습)과 실험 2(누적 흐름 g6의 50·100지점 비교)를 수행했습니다. 실험 1은 Closed-world와 Open-world 다중 분류를 주 결과로, Open-world 이진 분류를 보조 결과로 정리합니다. **실험 2는 monitored trim0의 Closed-world에서만**, 동일한 분할·5-fold·고정 RF 설정으로 전체 특징 110↔160개와 g1+g6 53↔103개를 비교했습니다. 실험 2는 **학습 데이터 내부 CV만 평가했으며 test 결과는 포함하지 않습니다.**

- 실험 1 실행 출력 포함 노트북: `MLB_RF_Experiment1.ipynb`
- 실험 2 실행 출력 포함 노트북: `MLB_RF_Experiment2.ipynb`
- 기존 그룹 제거 결과: `MLB_RF.ipynb`의 Ablation 출력

- 주요 파일: 실험 1의 `rf_group_only_summary.csv`, `rf_group_only_report_table.csv`와 실험 2의 `rf_g6_resolution.csv`, `rf_g6_resolution_comparison.csv`, `paired_fold_differences.csv`
- 공통 조건: trim0, `split_seed42.csv`, `StratifiedKFold(5, shuffle=True, random_state=42)` 및 고정 RF 설정. 실험 1은 g6 50지점을 사용했고 실험 2에서는 g6 50/100지점을 비교했습니다.
- RF 설정은 이전 그룹 제거 실험에서 사용한 값으로 고정했습니다. 조건마다 다시 튜닝하지 않았습니다.

**실험 2 요약(Closed-world CV만):** 전체 110→160개 특징은 0.8476→0.8476(표시 자릿수 기준 동률), g1+g6 53→103개 특징은 0.7918→0.7998(+0.0080, 약 +0.80%p)입니다. 따라서 RF의 **기본 기준은 전체 110개 + g6 50지점으로 유지**합니다.

## 1. 공통 설정과 실험 방법

- 데이터: 실험 1은 mon 19,000건, unmon 10,000건에 정보 열 6개를 제외한 110개 특징(g6 50지점)을 사용합니다. 실험 2는 mon 19,000건 중 train 15,200건만 CV에 사용하고, 다른 특징 60개는 고정해 g6만 50↔100개로 교체합니다(전체 110↔160개 및 g1+g6 53↔103개).
- 공유 분할: mon 학습 15,200 / 평가 3,800, unmon 학습 8,000 / 평가 2,000. 기존 `split_seed42.csv`를 사용했습니다.
- 모델: `RandomForestClassifier(n_estimators=100, max_depth=20, max_features="sqrt", min_samples_leaf=1, class_weight=None, random_state=42, n_jobs=-1)`.
- 전처리: 표준화·로그 변환·상수 특징 제거 없이 이전 RF와 같은 특징 구성을 유지합니다.
- 실험 1은 full + g1\~g6 단독의 7조건을 비교합니다. 실험 2는 Closed-world에서 전체 특징 50/100과 g1+g6 50/100의 4조건을 비교합니다. 같은 과제에서는 데이터 행 순서와 CV fold를 고정하고 입력 특징 열만 바꿉니다.
- CV 정확도로 특징 구성을 비교합니다. 실험 1은 같은 공유 test 기록의 정확도와 Macro-F1을 별도로 기록하고, 실험 2는 **train 내부 CV만 수행했으며 test를 평가하지 않았습니다.** test 결과를 후속 특징 선택에 사용하지 않습니다.
- 실행 환경 기록: scikit-learn 1.6.1. 트리 학습은 CPU를 사용합니다.

그룹 제거(Ablation)는 전체에서 그 그룹을 뺐을 때의 손실을, 단독 학습(Group-only)은 해당 그룹만 사용했을 때의 예측 성능을 봅니다. 두 결과를 함께 읽으면 정보 중복·보완 가능성을 검토할 수 있으나, 정보량이나 인과적 기여를 직접 측정한 것은 아닙니다.

## 2. 실험 1. Feature Group별 단독 학습

### 2-1. Closed-world — 전체 110개 CV = 0.8476 ± 0.0068

mon 95개 사이트 번호를 구별합니다. 전체 특징의 최종 평가 정확도는 0.8561, Macro-F1은 0.8553입니다. 아래 제거 시 변화는 기존 RF Ablation의 CV 결과입니다.

| 그룹 | 특징 수 | 단독 CV ± 표준편차 | 최종 평가 정확도 | 제거 시 CV 변화 | 읽는 법 |
| --- | --- | --- | --- | --- | --- |
| g6 누적 흐름 | 50 | 0.7482 ± 0.0054 | 0.7645 | -0.0218 | 단독 1위이며 제거 손실도 큼 |
| g2 순서·위치 | 17 | 0.6548 ± 0.0089 | 0.6697 | -0.0049 | 단독 2위이나 제거 손실은 상대적으로 작음 |
| g5 시간·속도 | 31 | 0.5559 ± 0.0072 | 0.5732 | -0.0111 | 단독·제거 결과에서 모두 기여 관찰 |
| g1 패킷 개수·비율 | 3 | 0.4566 ± 0.0055 | 0.4721 | -0.0014 | 단독 성능은 있으나 전체에서 추가 기여는 작음 |
| g3 연속 묶음 | 6 | 0.4417 ± 0.0039 | 0.4497 | -0.0012 | 단독·제거 양쪽에서 상대적으로 낮음 |
| g4 초반·후반 방향 | 3 | 0.2400 ± 0.0089 | 0.2539 | -0.0264 | 단독 최하위지만 제거 손실 1위: 보완 가능성 |

**해석**

- **g6는 단독 1위(0.7482), 제거 손실 2위(-0.0218)**입니다. 누적 흐름은 RF에서도 독립적으로 유용하고, 전체 구성에서도 추가 기여가 관찰됩니다. 다만 대체 불가라고 단정하지 않습니다.
- **g4는 단독 최하위(0.2400)지만 제거 손실은 1위(-0.0264)**입니다. 단독으로 설명하기 어려운 정보를 다른 그룹과 결합해 활용했을 가능성이 있습니다. 단독 성능만 보고 제거하면 안 됩니다.
- **g2는 단독 2위(0.6548)지만 제거 손실은 -0.0049**입니다. 다른 그룹이 비슷한 정보를 제공할 가능성과, 전체 구성에서의 상호작용을 함께 고려해야 합니다.
- g5는 단독 3위(0.5559), 제거 손실 3위(-0.0111)입니다. g1·g3도 단독 예측 성능은 있으나, 현재 전체 구성에서의 추가 기여는 상대적으로 작습니다.
- g6 단독에서 전체 특징으로 바꾸면 CV가 약 0.0995, 약 10%p 높습니다. g6만으로 충분하다고 결론 내리지 않습니다.
- g1의 총 패킷 수가 g6 끝값과 완전히 같다고 가정하지 않습니다. 끝값이 송신 수-수신 수라면 총량인 송신 수+수신 수와는 다르므로, 중복의 원인은 추가 확인이 필요합니다.

| 지표 | 값 | 분모와 의미 |
| --- | --- | --- |
| 전체 CV 정확도 | 0.8019 ± 0.0060 | 학습 구간 5-fold 정확도 평균과 표준편차 |

**해석**

- 단독 순위의 상위는 Closed-world와 같은 **g6 → g2 → g5**입니다. g6 단독 CV 0.7228에서 전체 0.8019로 약 0.0790, 약 7.9%p 높아집니다.
- 전체 정확도 0.8166을 monitored 사이트 식별 정확도로 읽으면 안 됩니다. 실제 mon의 사이트 번호 정답률은 **0.7276**이며, 실제 mon의 약 22.76%는 unmon으로 예측했습니다.
- 전체 모델은 unmon을 0.9855로 잘 걸러내지만 mon을 놓치는 경우가 남아 있습니다. 관심 밖 기록 배제 성능과 관심 사이트 식별 성능을 함께 보고해야 합니다.
- g6 단독의 mon 사이트 정답률은 0.6371, 전체는 0.7276입니다. 다른 그룹을 함께 썼을 때 mon 사이트 번호 식별도 개선됐습니다.
- 기존 RF 실험에는 Open-world 다중 Ablation 결과가 없습니다. 이 과제에서 각 그룹을 제거했을 때의 기여 순위는 이번 단독 실험만으로 확정할 수 없습니다.

## 3. LR·SVM 결과와 연결해서 읽기

아래 LR·SVM 값은 팀에서 공유한 보고서의 값입니다. RF는 이번 실행 출력에 근거합니다. 모델별 전처리와 하이퍼파라미터가 다르며 SVM 전체 구성은 중복 특징을 제외한 109개이므로, 완전히 동일한 입력 조건의 순수한 모델 효과를 분리한 비교는 아닙니다.

| g2 순서·위치 | 0.3332 | 0.6548 |
| g5 시간·속도 | 0.3095 | 0.5559 |
| g1 패킷 개수·비율 | 0.1486 | 0.4566 |
| g3 연속 묶음 | 0.1927 | 0.4417 |
| g4 초반·후반 방향 | 0.1476 | 0.2400 |

- 두 모델 모두 g6가 단독 1위입니다. 같은 누적 흐름 특징을 RF가 현재 설정에서 더 잘 활용했습니다. 비선형 패턴 활용 가능성은 설명 후보이지만 이 표만으로 원인을 확정할 수는 없습니다.
- 두 모델 모두 g4는 Closed-world 단독 최하위지만 제거 시 손실이 상대적으로 큽니다. 단독 성능만으로 특징을 제거하면 안 된다는 결론이 일치합니다.
- 이진에서는 LR 단독 1위가 g4(0.7268), RF 단독 1위는 g6(0.8092)입니다. 특징 그룹의 유용성 순위는 모델과 과제에 따라 달라집니다.

### 3-2. 특징 구성 선호와 해상도 결과의 구분

- 공유된 SVM의 Closed-world 결과에서 g1+g6 53개는 CV 0.8523, 전체 109개는 0.8428이었습니다. LR의 실험 2에서 g1+g6 53개는 0.4533, 전체 110개는 0.6630이었습니다. 모델별 입력 열과 전처리가 다르므로 모델 효과만을 분리한 직접 비교는 아닙니다.
- **RF에서도 g1+g6를 실제 실행했습니다.** Closed-world CV는 g1+g6 53개에서 **0.7918 ± 0.0084**, 103개에서 **0.7998 ± 0.0042**였습니다. 같은 설정의 RF 전체 110개는 **0.8476 ± 0.0068**으로, g1+g6 100지점보다 약 4.78%p 높았습니다.
- SVM에서는 g1+g6 조합이 전체보다 높았지만, 이번 RF에서는 **전체 구성이 더 높았습니다**. 특정 조합의 우수성을 다른 모델로 일반화하지 않습니다.
- LR 보고서의 실험 1 전체 0.6626과 실험 2의 0.6630은 서로 다른 실행의 보고값입니다. 차이를 임의로 없애거나 같은 수치로 통일하지 않았습니다.

## 4. 실험 2. 누적 흐름(g6) 표현 해상도 비교 — Closed-world 완료

**목적:** g6 누적 흐름의 샘플 지점 수를 50개에서 100개로 늘렸을 때 RF의 Closed-world 95클래스 분류 성능이 개선되는지 확인합니다.

**실험 조건**

- 데이터: monitored trim0 19,000건. 원본 50지점 `features_mon_trim0.csv`와 100지점 `cumul100_mon_trim0.csv`를 `record_id`로 정렬·결합했습니다. 실행 로그에서 ID·메타데이터 정합성을 확인했고, 기존 g1\~g5 60개 특징은 변경하지 않았습니다.
- 기존 `split_seed42.csv`: train 15,200건 / test 3,800건. **test는 실험 2에서 평가하지 않았고**, train에 동일한 5-fold 층화 CV(`shuffle=True`, `random_state=42`)를 적용했습니다.
- 고정 모델: `RandomForestClassifier(n_estimators=100, max_depth=20, max_features="sqrt", min_samples_leaf=1, class_weight=None, random_state=42, n_jobs=-1)`. 전처리·튜닝·fold를 새로 바꾸지 않았습니다.
- 비교 조건: 전체 특징의 g6 50→100(110→160특징) 및 g1+g6의 g6 50→100(53→103특징). 각 구성의 `100지점 - 50지점` 차이를 측정했습니다.

### 4-1. CV 결과

| 특징 구성 | g6 지점 수 | 전체 특징 수 | 5-fold CV 정확도 ± 표준편차 | CV Macro-F1 | 동일 구성 50지점 대비 |
| --- | --- | --- | --- | --- | --- |
| 전체(g1\~g6) | 50 | 110 | **0.8476 ± 0.0068** | 0.8464 | 기준 |
| 전체(g1\~g6) | 100 | 160 | **0.8476 ± 0.0068** | 0.8463 | **+0.0000** (표시 정밀도) |
| g1+g6 | 50 | 53 | **0.7918 ± 0.0084** | 0.7892 | 기준 |
| g1+g6 | 100 | 103 | **0.7998 ± 0.0042** | 0.7975 | **+0.0080** (약 +0.80%p) |

- 전체 구성에서는 100지점으로 늘려도 평균 CV 정확도가 **소수 넷째 자리까지 같았습니다.** 동일 fold 비교에서 향상된 fold는 **2/5개**입니다. Macro-F1도 0.8464→0.8463으로 실질적인 개선이 관찰되지 않았습니다.
- g1+g6에서는 평균 CV 정확도가 **0.7918→0.7998(+0.0080)**, Macro-F1이 **0.7892→0.7975(+0.0083)**로 상승했고, 개선된 fold는 **4/5개**였습니다. 다만 100지점의 g1+g6조차 전체 50지점의 0.8476보다 약 **0.0478(4.78%p)** 낮습니다.
- CV 표준편차와 개선된 fold 수만으로 유의성을 확정할 수 없습니다. 표준편차는 신뢰구간이 아닙니다.

### 4-2. 계산 비용

| 특징 구성 | g6 50지점: 5-fold fit 합계 | g6 100지점: 5-fold fit 합계 | 변화 |
| --- | --- | --- | --- |
| 전체 | 118.18초 | 197.16초 | 약 +66.8% |
| g1+g6 | 134.18초 | 194.75초 | 약 +45.1% |

시간은 **fold별 모델 fit 시간의 합계**이며 단일 벽시계 실행 시간이나 재실행 시간은 아닙니다. 특히 전체 50지점은 이전 완료 결과를 **5/5 fold 재사용**했기 때문에 이번 세션에서는 해당 모델을 다시 학습하지 않았습니다. 전체 100지점, g1+g6의 두 조건은 이번 실행에서 각 5개 fold를 새로 계산했습니다. 성능 개선이 확인되지 않은 전체 160특징 구성은 추가 계산 비용을 감수해 채택할 근거가 약합니다.

### 4-3. 팀의 LR·SVM 해상도 결과와 비교 (전체 특징 구성)

| 모델 | 전체 + g6 50지점 CV | 전체 + g6 100지점 CV | 변화 |
| --- | --- | --- | --- |
| LR | 0.6630 ± 0.0069 | 0.6814 ± 0.0090 | +0.0184 |
| SVM | 0.8428 ± 0.0051 | 0.8524 ± 0.0080 | +0.0095 |
| **RF** | **0.8476 ± 0.0068** | **0.8476 ± 0.0068** | **+0.0000 (표시 정밀도)** |

LR·SVM의 전체 구성에서는 100지점 확장에 따른 개선이 관찰됐지만, **RF에서는 같은 효과가 확인되지 않았습니다.** 모델별 전처리·특징 수·하이퍼파라미터가 달라 절대 정확도를 순수한 모델 우열로 해석할 수 없습니다. 특히 SVM의 기존 전체 50지점 입력은 중복 특징 제거 후 109개, RF는 110개입니다.

**실험 2 결론:** RF의 현재 고정 설정에서 **전체 110특징 + g6 50지점을 기본 구성으로 유지**합니다. g1+g6에서는 100지점의 소폭 개선을 확인했지만, 전체 구성보다 낮으므로 기본 구성을 대체하지 않습니다. 100지점의 이점이 모든 모델·과제에 공통적이라고 주장하지 않습니다. 현재 100지점 입력은 monitored만 있어 **Open-world의 해상도 비교는 미실시**입니다. 100지점 CSV의 추출 방식이 50지점과 같고 지점 수만 다른지 여부는 실험 코드만으로 완전히 증명되지 않습니다.

## 5. 의사결정 A 제안 — 실험 2 반영

**RF의 공통 기준은 전체 특징 110개 + g6 50지점으로 유지합니다.** 실험 1에서 전체 구성이 모든 단독 그룹보다 높았고, 실험 2에서도 전체 160개 특징으로 확장했을 때 Closed-world CV 개선이 확인되지 않았습니다. 최종 test 성능(Closed-world 0.8561)은 실험 1의 50지점 기준 모델에만 해당합니다.

- **전체 160개 특징 확장은 RF의 우선 개선안으로 추천하지 않습니다.** 전체 CV가 표시 정밀도 기준 0.8476으로 동일했으며 CV fit 시간 합계는 약 66.8% 증가했습니다. LR·SVM에서는 개선됐으므로 팀 전체의 모델별 비교표에는 후보와 관찰 결과를 구분해 남깁니다.
- **g1+g6 100지점은 축소 조합 내 개선으로만 해석**합니다(0.7918→0.7998). 전체 110개 기준(0.8476)보다 낮으며 RF의 최적 조합으로 확정하지 않습니다.
- **RF 후속 축소 조합 후보:** g6+g2를 우선 검토하고, g4 또는 g5를 더하는 소수 조합을 비교할 수 있습니다. g6·g2는 단독 상위이고 g4·g5는 기존 Ablation에서 추가 기여가 관찰됐다는 근거입니다. 이 조합들의 실제 성능은 아직 측정하지 않았습니다.
- g1·g3·g4를 단독 성능만으로 제거하지 않습니다. 다른 그룹을 포함한 축소 조합은 동일 CV로 검토하며 기존 full 결과를 공통 기준으로 유지합니다.

- 팀 공통 비교표를 확정할 때 모델별 데이터 분할·행 순서·전처리·평가 지표와 특징 수 차이를 함께 기록합니다.

## 7. 한계와 실행 기록

- **설정 고정 비교입니다.** 전체 특징에서 선택한 RF가 3개 특징의 단독 그룹에서도 최적인 것은 아닙니다. 이번 결과는 고정 RF에서의 유용성 비교이며 각 그룹의 최대 성능이나 순수 정보량의 측정은 아닙니다.
- **sqrt 규칙의 차원 의존성이 있습니다.** max\_features는 모두 sqrt이지만 명목상 분기 특징 수는 full 10, g1 1, g2 4, g3 2, g4 1, g5 5, g6 7입니다. 조건별 차이를 특징 정보만의 차이로 단정하지 않습니다.
- **표준편차는 신뢰구간이 아닙니다.** 5개 fold는 독립 반복 실험이 아니며, 개선 폭이 fold 표준편차의 몇 배라는 이유만으로 통계적 유의성을 주장하지 않습니다. `paired_fold_differences.csv`는 같은 fold에서의 차이를 확인하는 자료입니다.
- **단독과 제거 결과는 인과적 기여의 분해가 아닙니다.** 다른 그룹과의 상호작용과 모델의 대체 학습 가능성이 있습니다. 기준선 대비 개선 폭의 비율을 특정 그룹의 기여율로 해석하지 않습니다.
- **Open-world는 수집 흔적의 영향 가능성을 고려합니다.** 이번 실험은 기존 특징을 유지한 비교이며, 수집 흔적을 제거한 통제 실험은 아닙니다. Closed-world라는 이유만으로 수집 흔적이 전혀 없다고 단정하지도 않습니다.
- **새로 학습한 구간과 재사용 구간을 구분합니다.** 실험 1 실행 로그에서는 Closed-world·다중 14조건이 완료 결과를 재사용했고, 이진 7조건이 새로 계산됐습니다. 재사용은 동일 입력·설정·버전의 식별값을 확인하는 코드 경로입니다. 전체 최초 학습 시간은 이 재실행 로그만으로 계산할 수 없습니다.
- **수치 출처와 반올림을 구분합니다.** 표는 노트북에 표시된 결과를 기준으로 했습니다. 변화량은 기존 출력의 delta 값을 사용하여 반올림된 평균끼리 직접 뺀 값과 0.0001 정도 다를 수 있습니다. 기존 Closed-world g4 제거 결과는 완료 로그 0.8213과 결과 표 0.8212가 달라, 최종 수치 확정 시 원본 CV CSV 또는 fold 점수 확인이 필요합니다. 본문은 기존 표의 변화량 -0.0264를 사용했습니다.
- **Closed-world 해상도 검증은 완료했지만 범위가 제한됩니다.** 전체 50→100에서 CV 개선은 관찰되지 않았고, g1+g6에서만 소폭 개선됐습니다. test·Open-world 해상도는 평가하지 않았습니다. 지점 수 비교만으로 전체 특징의 충분성이나 모든 모델·과제의 개선을 증명할 수 없습니다.
- **해상도별 sqrt 분기 후보 수 차이:** 전체 110→160특징일 때 약 10→12개, g1+g6 53→103특징일 때 약 7→10개입니다. 모델 설정이 같아도 실제 분기당 고려 특징 수는 달라지므로 100지점 효과를 표현력의 변화만으로 단정하지 않습니다.
- **100지점 추출 정의는 별도 검증 대상입니다.** 실행 코드가 ID·라벨·특징 개수 및 고정된 g1\~g5의 일치를 검사했지만 추출 알고리즘 자체가 기존 50지점과 같은지 독립 검증하지는 못합니다.
